## PrintOS

> PrintOS é uma assistente empresarial para gráficas que centraliza pedidos, clientes, produção e visão operacional em uma experiência simples e organizada. A aplicação utiliza uma camada de dados integrada ao Supabase. Desenvolvido com TypeScript/React, TypeScript, CSS.

### Sobre o projeto

O PrintOS foi concebido como uma assistente empresarial para gráficas. A proposta é ajudar o responsável a organizar e acompanhar a operação, reduzindo processos espalhados e tornando as informações mais fáceis de consultar.

**O PrintOS não processa pagamentos, não movimenta dinheiro da empresa e não funciona como carteira ou gateway de pagamento.**
