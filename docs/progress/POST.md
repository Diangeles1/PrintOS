# PrintOS — Evolução do projeto

**Atualização: 09/09/2026**

PrintOS é uma assistente empresarial para gráficas que centraliza pedidos, clientes, produção e visão operacional em uma experiência simples e organizada. A aplicação utiliza uma camada de dados integrada ao Supabase. Desenvolvido com TypeScript/React, SQL, TypeScript, CSS.

## Direção do produto

O PrintOS continua sendo desenvolvido como uma assistente empresarial para gráficas, com foco em organização operacional, clareza das informações e uma experiência simples para o responsável pela empresa.

## Segurança

O projeto não deve armazenar ou processar dinheiro da empresa. Arquivos `.env`, credenciais, tokens e chaves privadas ficam fora do versionamento.

## Próximos passos

A evolução deve continuar a partir das necessidades reais identificadas no projeto, priorizando usabilidade, organização e confiabilidade.
